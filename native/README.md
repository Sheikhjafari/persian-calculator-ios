# ماشین‌حساب نیتیو آیفون

نسخهٔ SwiftUI ماشین‌حساب پوشهٔ `web` برای iOS 16 و بالاتر. جمع و تفریق اعشاری دقیق، ارقام فارسی، تغییر علامت، حذف رقم و پاک‌کردن کامل دارد. محاسبات محلی است و به اینترنت یا سرور وب نیاز ندارد. داده‌ها فقط تا زمان اجرای برنامه در حافظه می‌مانند.

## اجرا روی آیفون با حساب رایگان

1. پوشهٔ `native` را به یک مک دارای Xcode منتقل کنید.
2. فایل `Calculator.xcodeproj` را در Xcode باز کنید.
3. از Xcode → Settings → Accounts حساب اپل خودتان را اضافه کنید.
4. در target با نام Calculator، بخش Signing & Capabilities، گزینهٔ Automatically manage signing را روشن و Personal Team خودتان را انتخاب کنید. اگر Bundle Identifier تکراری بود، `com.ali.personalcalculator` را به شناسه‌ای یکتا تغییر دهید.
5. آیفون را به مک وصل کنید، پیام Trust را تأیید کنید و در صورت درخواست Xcode، Developer Mode را در Settings → Privacy & Security فعال کنید؛ ممکن است راه‌اندازی مجدد لازم باشد.
6. آیفون را به عنوان مقصد اجرا انتخاب کنید و Run را بزنید.

حساب رایگان برای آزمایش شخصی کافی است. پروفایل رایگان پس از ۷ روز منقضی می‌شود؛ برنامه باید دوباره از Xcode ساخته و نصب شود. انتشار در App Store معمولاً عضویت پولی می‌خواهد.

- [مقایسه حساب‌های اپل](https://developer.apple.com/support/compare-memberships/)
- [فعال‌کردن Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)

## آزمون‌ها

`swift test` را در این پوشه اجرا کنید. هستهٔ محاسبات مستقل از SwiftUI است و روی لینوکس دارای Swift هم آزمایش می‌شود. داده‌های مرجع شامل ۱۶۰۱۴ وضعیت از ماشین‌حساب اصلی وب است و نتیجه، عبارت، عملگر و وضعیت ورود را مقایسه می‌کند. برای بازسازی داده‌ها با Node، از ریشهٔ پروژه اجرا کنید:

```sh
node native/Tests/generate-fixtures.cjs
```

برای بررسی ساخت رابط روی مک بدون امضای حساب:

```sh
xcodebuild -project Calculator.xcodeproj -scheme Calculator -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

این پوشه پروژه و سورس است، نه IPA امضاشده. ساخت SwiftUI و بررسی ظاهر روی شبیه‌ساز یا دستگاه نیازمند Xcode روی مک است. آیکون اختصاصی هنوز اضافه نشده است.

## نتیجهٔ بررسی در این محیط

در ۲۰۲۶-۰۹-۱۲ با Swift 6.0 در کانتینر لینوکس، هر دو آزمون شامل تطبیق ۱۶۰۱۴ وضعیت وب با موفقیت اجرا شدند. ارجاعات فایل‌های پروژه و XML طرح اجرای مشترک هم بررسی شدند. ساخت و بررسی تصویری رابط iOS در این محیط انجام نشده است.


## ساخت ابری انجام‌شده

ساخت دستگاه با Xcode 26.3 و آزمون‌های هسته روی مک گیت‌هاب موفق شدند. خروجی بدون امضا در `output/Calculator-unsigned.ipa` دانلود و checksum آن تأیید شده است. این فایل به امضای حساب اپل قبل از نصب نیاز دارد. اطلاعات بخش بررسی لینوکس در بالا مربوط به مرحلهٔ اولیه است؛ ساخت iOS اکنون انجام شده، اما اجرای تصویری شبیه‌ساز جدید و نصب واقعی روی گوشی هنوز تأیید نشده‌اند.
